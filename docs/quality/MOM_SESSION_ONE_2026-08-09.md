## Product feedback → backlog (priority)

### P0 — blocks trust / correctness (IEB LS)

1. **Bank depth / shortfall**  
   Asked ~**200 marks**, generation only delivered ~**94**. Same class of failure as Dad. Teachers must not see “thin pack” as normal — AI fill + more LS exemplars ingested.

2. **IEB paper architecture (Section A / Question 1)**  
   Real IEB-style papers open with **Question 1** as easier objective items (MCQ, terminology, matching columns / grids), then longer Q2+. Numbering like **1.1, 1.2, …**. Demo pack looked like many short items without that structure — weaker learners need an easy start.

3. **Memo = marking guideline with Q+A**  
   Prefer **question then answer** in the memo (easier while marking). Award marks **beside the mark point**, not only at end of line. Longer questions must not collapse to one-word answers; **describe / compare / distinguish** need memo shape that matches verb (similarities vs differences, etc.). Optional: show Bloom / higher-order tip on the memo line while marking.

4. **Export as separate documents (not one PDF blob)**  
   Paper, marking guideline, and Bloom analysis should be **separate files** (or clearly separated downloads). Bloom sheet needs the **assessment title/topic** (e.g. prelim) at the top. Memo should share the **same header family** as the paper, labelled as marking guideline.

### P1 — wizard & curriculum UX (IEB)

5. **Wizard field order:** **Syllabus (IEB / CAPS) → Subject → Grade → Term/cycle → assessment type** (types filtered by term). Aligns with Dad’s “exam body early” intent; Mom wants syllabus **first**.

6. **Term ↔ type dependency:** e.g. trial/prelim usually **cycle/term 3** (sometimes 2 if syllabus finished early); June exam must not appear in term 1. Disable/explain invalid combos.

7. **Cycles language:** Some schools say **cycle** instead of term (≈ four cycles/year). Support label or synonym without inventing a fifth calendar.

8. **Topics > rigid term boxing (esp. IEB):** IEB schools sequence topics by learner maturity more freely than DBE. Prefer **all relevant topics selectable** (multi-select / multi-term). DBE may still want term hints. Topic model should reflect **strands** (e.g. diversity / life / change & continuity → evolution) with **grade-specific chapters** — reproductive system called out as missing; trial/prelim should expose full G12 set.

9. **Difficulty / Bloom focus simplify:** Keep difficulty for diagnostic/class use, but **default Balanced**. Formal prelim/trial **must** be balanced — she would rarely want “only higher order” for marks. Prefer fewer advanced knobs that complicate the path.

10. **Advanced defaults:** Prefer **empty / teacher chooses** rather than pre-ticked options. Hide Maths-only controls (e.g. calculator) on Life Sciences.

### P2 — templates, a11y, review UX

11. **School templates = full layout rules**, not cover-only: font, size, line spacing (1.5), indent/hanging, alignment/justified — per school (e.g. Trinity House vs others). Cover + mark sheet alone are not enough.

12. **Accessibility font override:** Real need for enlarged print (e.g. **18 pt** for a learner with vision needs) — template or export variant later.

13. **Review clarity:** Show **mark allocation** clearly per item; reduce confusing stem wording (demo biology Q confused “state concept / apply…”).

14. **Signup email confirmation** friction during pilot (same as Dad) — keep confirm-off for parent sessions.

### Later / nice-to-have

15. Graphs + reserved **spaces for diagrams** in paper/answer sheet.  
16. Bloom taxonomy / IEB **Aims 1–2–3** percentages kept current when IEB revises.  
17. Syllabus **year** variants (older adapted syllabi for special accommodations).  
18. Teacher-gated generation so packs don’t test chapters she hasn’t taught yet.  
19. Word-style heading styles as a mental model for school formatting (she already thinks that way).
